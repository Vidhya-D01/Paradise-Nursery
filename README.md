# Paradise Nursery

## Project Overview
Paradise Nursery is a plant nursery landing-page project designed to introduce customers to the nursery, showcase its purpose, and provide information about the company.

## Project Name
Paradise Nursery

## About the Project
The landing page presents Paradise Nursery as a welcoming place for plant lovers. It highlights the nursery's focus on helping customers discover plants and create greener, healthier spaces.

## Technologies
- React
- JavaScript
- CSS

## Main Files
- `README.md` — project overview and details.
- `AboutUs.jsx` — About Us section with company information.
- `App.css` — styling for the landing page, including its background image.

## Getting Started
1. Create or open a React project.
2. Add `AboutUs.jsx` to the `src` folder.
3. Add the CSS from `App.css` to your app's stylesheet.
4. Run the project using your React development environment.
