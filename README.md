# Paradise Nursery

## Project Overview

Paradise Nursery is an online plant shopping application designed to help customers explore, select, and purchase different types of plants easily.

## Project Name

e-plantShopping - Paradise Nursery Shopping Application

## About the Project

The e-plantShopping application, also known as Paradise Nursery, is an online plant shopping platform that allows customers to browse different plants, view product details, add products to their shopping cart, and purchase plants easily. It provides a simple and user-friendly shopping experience for plant lovers.

## Key Features

- Attractive landing page.
- Company information page.
- Display of different plants.
- Product listing page.
- Add plants to shopping cart.
- Remove plants from shopping cart.
- Update product quantities.
- View total cart price.
- Easy navigation between pages.

## Technologies Used

- React.js
- JavaScript
- CSS
- HTML

## Main Files

- README.md - Project overview and details.
- App.jsx - Main application component.
- AboutUs.jsx - Company information page.
- App.css - Application styling.
- CartSlice.jsx - Shopping cart state management.
- CartItem.jsx - Shopping cart component.
- ProductList.jsx - Displays available plants.

## Getting Started

1. Download or clone the project repository.
2. Open the project in Visual Studio Code.
3. Install the required dependencies using npm install.
4. Run the application using npm start or npm run dev, depending on the project setup.
5. Open the application in your browser.

## Conclusion

Paradise Nursery provides a convenient online platform for customers to explore and purchase plants through a simple and user-friendly shopping experience.
